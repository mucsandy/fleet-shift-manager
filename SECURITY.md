# Security

The disconnected demo is a simulation. Its role selector demonstrates visibility and workflow rules; it does not authorize access to a server or protect shared records.

For a real deployment, enforce access on the backing SharePoint lists and document libraries. Hiding a button in Power Apps is not a replacement for list permissions. Validate each role with a separate test account and check direct list access as well as app navigation.

Do not submit personal data, real signatures, patient information, credentials or operational photographs in public issues. To report a suspected exposure, use GitHub's private vulnerability reporting when it is enabled for this repository. If unavailable, contact the maintainer privately before sharing details.

Accident reporting in this application does not replace the organization's required accident and damage reporting process.
