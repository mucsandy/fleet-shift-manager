# Contributing

Thanks for taking a look. A small improvement to a real handover problem is useful here.

For bugs, include the edition, screen, steps, expected behavior and result. Add your device or preview dimensions for layout issues. Use fictional people and registrations.

For larger workflow changes, start with an issue. Keep pull requests focused and describe what changed and how you checked it. Edit through Power Apps Studio where possible, then export and review the app alongside its source. Do not assume a text edit alone proves runtime behavior.

Never include operational photos, real signatures, credentials, tenant connections or private identifiers. See [Security](SECURITY.md) for sensitive reports.

Useful next contributions include clean-environment installation checks, the remaining workshop/replacement branches, physical-device and accessibility testing, and improvements based on other teams' routines.
